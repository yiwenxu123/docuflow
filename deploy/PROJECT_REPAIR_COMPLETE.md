## 🔧 使用方法

### 1. Web界面
```bash
cd deploy
./start_docuflow.sh web
# 访问 http://localhost:5003
```

### 2. 命令行 (交互模式)
```bash
cd deploy
python3 main_cli.py
```

### 3. 命令行 (参数模式)
```bash
cd deploy
python3 main_cli.py input.md output.html
```
